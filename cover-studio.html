How to export crisp PNGs (pick one):
1. Local server (best for the Download buttons): from the repo folder run python3 -m http.server 8099, open http://localhost:8099/cover-studio.html, then click ⬇ Download PNG. (Opening as a file:// path blocks PNG export for security — the buttons only work over http.)
2. Chrome DevTools (no server needed, pixel-perfect): right-click a design → Inspect → in the panel, right-click the highlighted <div class="panel"> → Capture node screenshot.
3. Edit the words: all text is plain HTML — change a headline by editing the text inside the panel. Swap a background by changing the image filename in the CSS at the top.
